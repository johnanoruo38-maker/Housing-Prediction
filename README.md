# EstimateIQ — House Price Prediction System

A production-quality, full-stack machine learning application that predicts house prices
using Scikit-learn, Flask, and a polished vanilla JS frontend.

```
project/
├── backend/
│   ├── app.py            Flask REST API
│   ├── utils.py          Validation + preprocessing helpers
│   ├── model.joblib      Trained model (generated by training script)
│   └── model_meta.json   Model metadata (generated by training script)
├── frontend/
│   ├── index.html        UI entry point
│   ├── styles.css        Responsive styles
│   └── script.js         Fetch API + state machine
├── dataset/
│   └── housing.csv       Training data
├── train_model.py        ML training pipeline
├── requirements.txt      Python dependencies
└── README.md
```

---

## Quick Start

### 1 · Install dependencies

```bash
pip install -r requirements.txt
```

### 2 · Train the model

```bash
python house_model.py
```

Expected output:
```
14:34:38  INFO   Linear Regression    MAE=$10,776  RMSE=$15,301  R²=0.9861
14:34:39  INFO   Random Forest        MAE=$13,348  RMSE=$16,638  R²=0.9836
14:34:39  INFO   ✓ Best model: Linear Regression (R²=0.9861)
14:34:39  INFO   Model saved → 'backend/model.joblib'
```

This produces `backend/model.joblib`, `backend/model_meta.json`,
and `backend/price_vs_size.png` (visualisation chart).

### 3 · Start the backend

```bash
cd backend
python house_app.py
```

The API starts on **http://localhost:5000** by default.

To change host/port:
```bash
HOST=0.0.0.0 PORT=8080 python app.py
```

### 4 · Open the frontend

Open `frontend/house.html` in any modern browser.
No build step required.

## API Reference

### `POST /predict`

Request:
```json
{
  "location": "urban",
  "size": 1200,
  "rooms": 3
}
```

Response:
```json
{
  "predicted_price": 255867
}
```

### `GET /health`
```json
{ "status": "ok", "model": "Linear Regression" }
```

### `GET /meta`
```json
{
  "model_name": "Linear Regression",
  "known_locations": ["coastal", "rural", "suburban", "urban"],
  "cat_features": ["location"],
  "num_features": ["size", "rooms"]
}
```

#### Validation Rules

| Field      | Type   | Constraints                                    |
|------------|--------|------------------------------------------------|
| `location` | string | One of: urban, suburban, rural, coastal        |
| `size`     | number | 100 – 20,000 sq ft                             |
| `rooms`    | number | 1 – 20                                         |

---

## Models

Two regression models are trained and compared automatically:

| Model             | Description                                                  |
|-------------------|--------------------------------------------------------------|
| Linear Regression | Fast, interpretable baseline; robust on linear relationships |
| Random Forest     | 200-tree ensemble; handles non-linearities well              |

The model with the highest R² score on the test set is saved to `model.joblib`.

---

## Bringing Your Own Data

Replace `dataset/house.csv` with any CSV that has these columns:
`location`, `size`, `rooms`, `price`

Then re-run `python house_model.py`.
